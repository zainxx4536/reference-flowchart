## 结构

- 物理主线：待发送用户信号 → 发射端 → 无线信道 → 用户信号与干扰、噪声叠加 → 接收机 → 本轮通信成功／失败。
- 接收机感知整个通信频带。新频谱和保留的历史构成下一状态；瀑布图含用户信号、干扰、噪声，不是已分离的干扰图。
- 接收端 Agent 运行 ADRLA。RCNN 是其中估计候选动作 Q 值的网络；ADRLA 是包含动作选择、经验记录和训练的整体算法。
- 可靠控制链路将下一轮频率从接收端送到发射端；业务信号方向相反。
- 保存本轮状态、动作、奖励及下一条频谱观测；随机回放时重建完整下一状态、构造目标并更新权重。

## 可复用的教训

1. 从“频谱状态 → 网络”开始会丢失发射、传播、干扰进入和接收结果；完整总图先画物理主线。
2. Q 是预期长期回报，r 是一次交互的即时奖励；选频不能简化成“眼下哪里空闲就去哪里”。
3. 原文经验为 `(S_t, a_t, r_t, s_(t+1))`。最后一项是新一行频谱，不是完整下一状态；只保存 r 不够。
4. 训练用 ε-贪心且关闭递归；经验充足时回放更新。训练结束固定权重，推理启用递归并选最大 Q。可用训练更新应在下一轮动作前完成。
5. 一轮结果输出后可继续通信，不虚构总终止条件。
6. RCNN 估计选频价值，不直接抵消混合接收信号中的干扰；原文未展开的同步、均衡、译码不补造成已实现模块。
